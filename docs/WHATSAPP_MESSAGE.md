## Feature List

### 👨‍🏫 For Teachers

**Class Management:**
- View assigned classes with grade, section, and room details
- Manage student roster (add, edit, remove students)
- Bulk import students via CSV upload
- Unique student ID validation across all classes

**Attendance Tracking:**
- Quick attendance marking (Present, Absent, Late, Left Early)
- Add comments for each attendance record
- Add new students on-the-fly while taking attendance
- Daily cutoff time prevents late edits (ensures data accuracy)
- Automatic holiday detection (no attendance on holidays)
- Mobile-optimized interface for on-the-go attendance

**History & Reports:**
- View attendance history by date
- Export attendance data to CSV
- Student lookup by ID (view individual student records)
- Filter and search functionality

**Profile Management:**
- Update personal information (name, mobile, grade, section)
- View account status and creation date

---

### 👨‍💼 For Administrators

**User Management:**
- Approve new teacher signups (two-stage approval process)
- View and manage all staff members
- Change user roles (Teacher ↔ Admin)
- Activate/deactivate accounts (master switch)
- View detailed user profiles
- Real-time updates when users are added/modified

**Attendance Oversight:**
- View attendance for any class across the school
- Filter by grade, section, and date
- Export attendance reports to CSV
- Cross-class visibility for oversight

**Student Management:**
- Search any student across all school years
- View complete attendance history per student
- Multi-year attendance tracking

**Data Archiving:**
- Two-stage archive process (safety-first approach)
- Generate CSV archives for entire school years
- Download and verify before purging
- Safe database cleanup for year-end transitions

**Dashboard:**
- Overview of pending approvals
- Active staff statistics
- Quick access to common tasks

---

### 🔐 Security Features

- **Authentication:** Email/password with Supabase Auth
- **Authorization:** Role-based access control (Admin/Teacher)
- **Approval Workflow:** Two-stage approval (signup → admin approval)
- **Master Switch:** Instant account deactivation
- **Data Protection:** Row-Level Security (RLS) policies
- **Input Validation:** Client and server-side validation
- **SQL Injection Prevention:** Parameterized queries
- **XSS Prevention:** React's built-in escaping
